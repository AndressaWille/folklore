Changelog
=========

0.1.1 (2026-10-15)
------------------

Documentation only; the code is the same as in 0.1.0.

* Shorter workflow page and simpler README.
* Tutorial notebook run with the package installed from PyPI.

0.1.0 (2026-10-15)
------------------

First public release.

* Galaxy masks, local-contrast detection in every filter, cross-filter
  matching, clump sizes and disk/outside classification.
* Clump polygons in pixel and sky coordinates (GeoJSON).
* Background-subtracted photometry on any cube, ready for SED fitting.
* Diagnostic plots for every step.
